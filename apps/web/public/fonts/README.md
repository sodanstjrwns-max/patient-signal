# Signal display fonts

- Signal Display Bold: Gmarket Sans Bold outlines, converted to WOFF2 and renamed to respect the reserved font name. Original: https://corp.gmarket.com/fonts/ (GmarketSansTTF.zip). License: SignalDisplay-OFL.txt, copied from the original font metadata.
- Chakra Petch Bold: https://github.com/google/fonts/tree/main/ofl/chakrapetch ; converted to WOFF2. License: ChakraPetch-OFL.txt.

Body text remains Pretendard. Font assets are served locally.
